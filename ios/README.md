# free_rollcall · iPhone

独立的原生 iPhone 工程，最低支持 iOS 18。将整个 `ios/` 目录单独复制出来即可开发，不需要上层 Python、桌面程序、账号文件或 `bot/` 仓库。

## 打开与运行

1. 使用 **Xcode 26 或更新版本**打开 `FreeRollcall.xcodeproj`，选择 `FreeRollcall` scheme
2. 选择 iPhone 模拟器后运行；安装到自己的 iPhone 时，在 `Signing & Capabilities` 中选择自己的开发团队，必要时修改 Bundle Identifier
3. 进入「账号管理」，点击右上角 `+` 填写账号、密码和可选备注
4. 回到「功能」→「进入课程」，应用会登录默认账号；也可以先在账号列表左滑，手动登录其他账号

第一个账号自动设为默认。默认账号和当前登录账号分开：手动登录后一直使用该账号，修改默认设置不会切换已登录账号。应用重新启动后，首次使用功能才重新登录。

## 功能

- 白底黑色主题，底部依次为功能、本地日志、账号管理；iOS 26 及以上使用系统原生标签栏，由系统提供液态玻璃、选中效果和滚动边缘处理；iOS 18 至低于 26 保留普通磨砂胶囊底栏
- 账号左滑提供登录、修改、默认、删除四个动作；编辑时密码默认可见，也可以隐藏
- 只展示学校当前学期课程，自动取齐结果，不显示“加载更多课程”；课程内展示可取得的签到历史，活动排在前面；可用的数字签到码直接显示
- 点击「点击此条目签到」会直接提交；数字签到随后查询本人状态，雷达按参考仓库的既定方法执行
- 本地日志保存时间、课程、签到形式、结果、账号和签到码；雷达显示「雷达签到」；中断或未核实的结果标记「待确认」
- 密码保存在本机 Keychain（系统钥匙串），账号配置及日志使用 SwiftData；删除账号保留历史日志，不上传日志或同步到云端

登录使用学校原始网页：等待表单、填写账号密码、触发原有提交，由学校页面处理加密。验证码等情况会显示当前网页；同一账号连续三次明确的凭证错误后转为网页登录。网络错误不计入这三次。

## 主要代码

| 位置 | 职责 |
| --- | --- |
| `FreeRollcall/App/AppState.swift` | 全局账号状态、登录任务、本学期课程加载、签到操作和日志归属 |
| `FreeRollcall/Services/WebAuthenticator.swift` | 原页面自动登录、人工处理、身份确认及凭证交接 |
| `FreeRollcall/Core/TronclassClient.swift` | 独立网络会话，课程、历史、详情及数字签到请求 |
| `FreeRollcall/Core/RadarSubmission.swift` | 参考 bot 的雷达请求、坐标计算、候选点顺序和成功判断 |
| `FreeRollcall/Core/Models.swift` | 身份、课程、活动和本人状态、分页与去重 |
| `FreeRollcall/Storage/LocalStore.swift` | 账号、钥匙串密码、签到记录和中断恢复 |
| `FreeRollcall/Views/` | 三个页面、课程及签到界面、账号编辑和网页登录 |

`Core` 是本地 Swift package（Swift 代码模块），与应用一起保存在本目录，不下载第三方运行依赖。账户与业务协调集中在 `AppState`，账号与日志存储集中在 `LocalStore`，第一版没有为每个职责再拆一层空壳。

## 本地检查

在此目录执行核心离线测试：

```sh
swift test --scratch-path .build/swiftpm
```

在 Xcode 中按 `Command-U` 运行账号与界面测试，也可指定本机实际安装的模拟器：

```sh
xcodebuild -project FreeRollcall.xcodeproj -scheme FreeRollcall \
  -destination 'platform=iOS Simulator,name=iPhone 17 Pro,OS=26.5' \
  -derivedDataPath .build/Xcode test
```

界面测试只使用虚构账号和内存响应，不连接学校。调试构建可在运行参数中加入 `--ui-fixture` 查看这些样例；正式构建没有该入口。正常运行不会显示样例数据。

模拟器也应保留 Xcode 默认的本地签名；关闭签名会导致钥匙串读写测试失败。真实认证的可选只读测试默认跳过，只有显式提供 `TEST_RUNNER_ROLLCALL_TEST_CREDENTIALS_PATH` 时才读取指定的本机账号文件并进行登录与课程查询，该测试不会提交签到，应用自身没有读取外部账号文件的入口。

构建、测试报告和本地截图放在 `.build/`，已加入忽略规则；说明与验证记录放在 `project_docs/`。不需要创建账号配置文件，不要将真实账号密码写入源码。

## 实现边界

- 历史接口在只读检查中返回重复页，且没有完整分页信息；应用保留已取得的数据并说明范围，不将这类返回声称为完整历史
- 雷达严格参考 `XMU-Rollcall-Bot` 的固定版本，不调用设备定位、不申请位置权限；开发只做离线一致性检查，真实效果按约定由使用者后续验证
- 数字签到有真实提交代码和本人结果复核；开发过程中未发起学校端真实签到，不能把离线测试视为真实签到成功记录
- 本机没有 iOS 18 运行时，最低部署目标与兼容分支已设置，iOS 18 真机或对应模拟器仍需单独验证
- 学校网页和非公开接口发生变化时可能需要适配；扫码及其他签到形式暂不实现
