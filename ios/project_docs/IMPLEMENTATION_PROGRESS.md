## 本轮交付

- `FreeRollcall.xcodeproj`：共享运行／测试配置，本地 Swift package，无外部运行依赖
- 三个白底黑色页面：功能、本地日志、账号管理；原生液态玻璃底栏及低版本普通材质分支
- 多账号配置、系统钥匙串密码、右滑登录／修改／默认／删除
- 当前账号与默认账号分开；按需登录、同账号过期重登、切换失败保留原会话、旧请求隔离
- 原网页自动填表登录，三次凭证失败或验证码时人工接管，登录后核实身份
- 全部可访问课程的分页读取、签到历史、活动优先排序、数字码展示
- 数字签到真实请求与本人结果核对；雷达完整移植参考算法，无手机定位分支
- 一次点击一条持久化日志；账号快照、失败原因、待确认、重启恢复、原账号核对
- 使用说明、源码职责、测试、原项目及参考仓库许可证

实现集中在 `AppState`、`LocalStore`、`WebAuthenticator` 与核心请求模块，没有将计划中的每个逻辑职责都拆成独立空壳文件。实际目录以 README 为准。

## 已取得的只读接口证据

这些检查仅认证和读取，没有提交数字或雷达签到，也没有保存真实响应或打印个人资料。

- `/api/profile` 返回 `id`、`user_no`、`name`；`id` 与原程序捕获的内部学生标识一致，`user_no` 与测试账号一致
- `/api/my-courses` 的 `conditions: {}` 返回 60 门课程的分页信息；原当前学期筛选只返回 11 门；响应有 `courses`、`page`、`page_size`、`pages`、`total`
- 课程历史返回 `rollcalls`，没有分页元信息；对抽查课程使用不同页码得到相同的两条历史记录
- 历史中的 `rollcall_status=finished` 与 `is_expired=false` 可以同时存在，不能仅凭后者认定正在签到
- 历史的本人状态与活动状态分开；详情的 `student_rollcalls` 中按 `student_id` 选择本人，其他同学的信息不进入应用模型、界面或本地日志
- 签到详情有 `number_code`、`status`、`end_time`，数字码保持字符串及前导零
- 原生 WKWebView 自动填表登录、获取身份、将网页凭证交给原生课程请求已在模拟器通过一次真实只读检查，约 6.6 秒；没有借助 Python 完成这次原生检查

没有分页元信息时，即使返回条数少于请求大小，也允许继续尝试下一页；空页或重复页停止。此类结果显示实际获取范围，不声称完整历史。
