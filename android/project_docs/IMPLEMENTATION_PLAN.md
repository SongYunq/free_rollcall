# 安卓独立版本实施计划

状态：已完成。创建和验收记录日期：2026-10-05。详见 [实施与验证记录](IMPLEMENTATION_PROGRESS.md)。

## 范围

仅新增 `android/` 工程。根目录 Python 核心、CLI、桌面端、`ios/` 和参考 `bot/` 保持原样。安卓参考现有接口与 iOS 交互，自行实现业务与本地存储，不依赖 Python 或 Swift 运行。

## 页面与交互

- 白色底色、黑色主题，灰色辅助文字，长条列表、统一图标宽度和对齐。
- 底部普通胶囊栏：功能、本地日志、账号管理；不模拟液态玻璃。
- 功能页默认打开，只包含“进入课程”。仅请求最新学期课程，内部完成课程分页，无“加载更多课程”。
- 课程签到页分页展示历史，数字码直接显示并保留前导零；自动补码不覆盖本人签到状态。已签到、迟到维持现有文案；仅明确未签到且已结束显示红色“缺勤”；进行中的未签到显示“正在签到”。
- 点击进行中的可用条目直接自动填写数字码并签到，雷达采用既有参考机器人流程。非活动记录可查看详情。
- 按后续用户反馈，账号仅通过右侧三个点打开登录、修改、设为默认、删除菜单，不再使用横向滑动。删除需确认，账号支持备注和密码显示切换。
- 手动成功登录后，全局沿用该账号；未登录使用功能时登录默认账号。设置默认不切换当前会话；编辑当前账号凭证或删除当前账号会使会话失效。
- 本地日志保留时间、课程、形式、结果、账号快照及签到码。删除账号不删除日志。提交前先落盘，异常中断保留可核对结果，核对只查询不再次提交。

## 技术实现

1. 独立 Kotlin / Jetpack Compose 工程，最低 Android 8（API 26），编译和目标 API 36。固定本机已有兼容依赖，包含 Gradle Wrapper。
2. `core/` 负责模型、响应解析、当前学期/历史分页、数字提交确认和雷达算法；可用离线测试替换网络。
3. `auth/` 使用受限 HTTPS WebView 加载统一身份认证，通过学校自身表单和加密脚本填入账号密码。验证码转网页处理，连续三次凭证错误转手动；网络错误不计入。读取个人信息验证账号身份后，建立独立的内存会话。
4. 每次登录清理网页登录状态；网络会话独立保存 Cookie，限定教学平台主机，禁止自动重试签到请求。只读查询过期后可重登同一账号。
5. `storage/` 使用 SQLite 事务保存账号元数据和日志；密码经 Android Keystore 的 AES-GCM 加密后保存，不写入日志，关闭系统备份。
6. `app/` 与 `ui/` 管理页面和全局会话，防止重复点击、账号切换和迟到返回的旧数据互相覆盖。数字提交后短暂只读重查，未确认仍诚实保留结果未知，不自动重发。
7. 雷达按参考版本 `c7de02b11da3433a047bab29dbbbbbb4c855a484` 的固定探针、距离交点和请求顺序实现，不申请定位权限。

## 验证与交付

- 单元测试：本人状态、缺勤边界、前导零、分页重复、当前学期条件、当前学生匹配、雷达载荷和顺序、提交结果/不重复重发。
- 模拟器离线测试：账号保存/密码加解密/默认账号/删除后日志、三个入口、三个点菜单、课程列表和历史码展示、日志核对；使用测试注入，不使用真实账号或提交真实签到。
- 完成调试安装包和 Release 编译、Lint 检查；不截图，视觉由用户验收。
- 新增 `android/README.md`、第三方说明和实施记录。构建产物和检查日志放在工程内的忽略目录。
- 最后核对变更仅在 `android/`，不自动 commit 或推送。

## 后续交互与性能修复

- 底部栏限制圆角范围并取消默认点击波纹，避免短暂灰色方块。
- 下拉刷新不额外显示默认圆圈，区分课程列表加载与详情、签到等操作；同一操作保留一个对应的加载动画。
- 本地数据库初始化、查询、事务和密码加解密在后台线程执行，接口响应解析也移至后台。
- 历史补码每批四条发布一次列表更新，复用日期解析和格式化结果；切换底部页面保留列表滚动状态。
- 增加优化且可安装的 `preview` 版本，关闭调试，保留与本机调试版一致的包名及签名供覆盖验收。
- 验证后台线程约束、菜单替代滑动、单一加载动画和实际优化包启动；设备上的流畅度由用户复测。
