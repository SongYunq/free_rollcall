# 安卓实施与验证记录

日期：2026-10-05。

## 完成范围

新增完整独立 `android/` 原生工程，当前版本 1.0.2，包名 `cn.freerollcall.android`。最低 Android 8.0，编译和目标 API 36。固定依赖与 Gradle Wrapper，支持 Android Studio 导入、调试、优化验收包以及 Release 编译。

1.0.2 的全目录检查、修复及最新验证结果见 [安卓检查与修复](ANDROID_AUDIT.md)。下方保留 1.0.1 的实施与验证记录。

本次仅新增安卓目录。通过变更前后 SHA-256 核对，全部已跟踪的 iOS 文件、根目录 Python 核心及其入口均未改变；原有工作流文档改动和 `bot/` 目录保持原样。未 commit 或推送。

## 界面与功能

- 白底黑色主题，普通胶囊底部栏，功能、本地日志、账号管理三个图标，长条列表、固定图标宽度和字段对齐。
- 账号仅通过右侧三个点展开登录、修改、设为默认、删除菜单，横向滑动不触发操作。支持多账号、备注、密码显示切换、删除确认、默认账号与全局当前账号。
- 统一身份认证使用受限 HTTPS WebView 和网页自有表单脚本，遇到验证码转为人工网页操作；三次凭证错误后转人工，网络失败不计入。个人信息确认账号身份，会话在内存中隔离。
- 功能页只显示“进入课程”。当前学期接口提供筛选条件，自动完成所有课程分页，不显示加载更多课程。
- 签到历史可分页、下拉刷新。数字码在列表中自动补齐，最多四个并发只读请求，保留前导零；补码不替换原有本人或活动状态。已签到和迟到保留原文案，明确的已结束缺勤标红，活动中的未签到显示正在签到。
- 活动条目直接签到，提交前记录本地尝试并重新确认活动状态。数字提交后最多查询三次本人结果，整个过程只有一次数字 PUT；结果未知时不自动重发。雷达采用既定参考机器人请求和交点算法，无定位权限。
- 本地账号和日志使用 SQLite，密码由 Android Keystore 的 AES-GCM 加密并绑定账号标识。删除账号保留日志快照；应用异常中断的处理中日志会恢复为待确认。日志核对必须使用对应账号，执行只读查询。
- 云备份和设备迁移排除所有实际存储域。网页登录结束后清理 WebView 的 Cookie、缓存和网页存储；已验证 API 会话使用独立 Cookie 容器。第三方移植署名和许可证包含在工程及安装包中。

## 1.0.1 交互与性能调整

- 底部项缺少圆角裁剪，默认点击波纹可以越出胶囊。现增加裁剪并取消默认点击反馈，只显示黑白选中状态。
- 额外圆圈来自下拉刷新组件：此前通用忙碌状态同时驱动默认刷新圈和页面动画。现按课程/历史列表加载分开管理状态，关闭默认刷新圈，保留单个自有动画。
- 账号取消横向拖动、位移动画和双层行布局，采用三个点下拉菜单。
- 数据库打开、恢复、查询和事务，以及密码加解密全部移到后台。接口响应解析和历史补码也在后台执行；每四条补码结果发布一次列表更新，日期解析/格式化结果复用，底部页面切换保留列表滚动位置。
- 账号保存由全局状态负责完成，切换页面不会中断已写入数据后的状态刷新。签到结果、账号身份和雷达请求顺序保持不变。
- 先前供用户安装的是 Debug 包。新增关闭调试并启用 Release 同等优化的 `preview` 包，使用同一调试签名，方便覆盖验收。设备上的实际卡顿程度没有本轮量化，需用户用新包复测，不能以模拟器通过功能测试替代真机流畅度验收。

实现依据：[Android Compose 性能指南](https://developer.android.com/develop/ui/compose/performance)、[交互反馈指南](https://developer.android.com/develop/ui/compose/touch-input/user-interactions/handling-interactions)。

设备测试使用工程内创建的专用 Android 16 模拟器及虚拟账号。测试代码与响应仅位于 `androidTest`，生产应用没有演示或自动化测试开关。未登录真实账号、未向学校提交签到、未截图。真实登录、验证码与学校服务响应，以及真机视觉效果由用户后续验收；Android 8 的兼容性通过最低版本与静态检查验证，本轮没有该版本的实际设备测试。
